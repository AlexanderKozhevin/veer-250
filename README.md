# Сумка «Веер» · 250 мм

Выкройка для ручной сборки кожаной сумки с двумя боковыми крыльями. На сайте можно вращать модель Three.js, открыть клапан, разнести детали и посмотреть их в плоском виде. [Открыть мастерскую](https://alexanderkozhevin.github.io/veer-250/)

| Размер | Значение |
| --- | ---: |
| Высота корпуса до верхней точки крыла | 250 мм |
| Полная высота с ручкой | 350 мм |
| Ширина по концам крыльев | 400 мм |
| Наибольшая глубина | 136 мм |

Выкройка реконструирована по фронтальному фото. Глубина, дно и внутренние крепления разработаны для этой версии. Посадку на выбранной коже предстоит проверить бумажным макетом и пробной сборкой.

## Файлы мастерской

- [Цельные лекала 1:1 на A3](docs/downloads/veer-250-a3.pdf) · 4 альбомных листа. Все детали помещаются целиком. Дно длиной 447,5 мм расположено по диагонали.
- [Лекала 1:1 на A4](docs/downloads/veer-250-a4.pdf) · 10 листов, линии реза и шва, контрольные метки, крепления и сгибы. Припуск по стачным швам A–D уже включён и равен 6 мм.
- [Материалы и иллюстрированная сборка](docs/downloads/veer-250-guide.pdf) · 6 страниц, ведомость материалов и восемь шагов.
- [Комплект с векторным раскроем](docs/downloads/veer-250-kit.zip) · три PDF, три листа CUT только с контурами и три соответствующие карты MAP с разметкой. Все 20 деталей разложены с учётом зеркальных копий. Единицы SVG — миллиметры.

Начните с листа 1. Выберите «Фактический размер» и измерьте квадрат 50 × 50 мм в двух направлениях и линейку 100 мм. Для комплекта A4 у дна D склейте листы 5 и 6 по регистрационным крестам.

## Материалы

Основная кожа 1,2–1,4 мм, ориентировочно 0,60–0,70 м². Карта занимает 878 × 663 мм. Для изнанки клапана и двух накладок нужно около 0,06 м² кожи толщиной 0,7–0,9 мм. Дополнительно потребуются вставка из кожкартона 142 × 116 мм, магнитная кнопка Ø 14 мм с шайбами, нить 0,55–0,65 мм, клей и отделка уреза. Латунный зажим на край клапана можно добавить после примерки.

На сайте можно сравнить стоимость отреза и полушкуры, включить в смету только нужные инструменты и открыть карточки товаров. Там же описаны выбор нити и приёмы для ручки, клапана и дна. [Материалы и смета](https://alexanderkozhevin.github.io/veer-250/#shopping) · [Как собрать сумку](https://alexanderkozhevin.github.io/veer-250/#assembly)

## Геометрия и сборка сайта

Размеры заданы в миллиметрах в `tools/pattern.py`. Панели разворачиваются по двум треугольникам с общей диагональю. Дно разворачивается полосами вокруг четырёх поперечных сгибов. Контуры клапана и ручки общие для 3D-модели и печати. Упругость, растяжение и прочность кожи требуют проверки на материале.

Для просмотра готовой версии достаточно раздавать каталог `docs` статическим HTTP-сервером. Внешние CDN не требуются. GitHub Pages публикует `main /docs`.

Для пересборки установите Node.js и Python с зависимостями из `requirements.txt`. Для PDF нужны системные шрифты DejaVu Sans, DejaVu Sans Bold и DejaVu Serif, либо Arial и Georgia на macOS. Каталог шрифтов можно указать в `PATTERN_FONT_DIR`.

```sh
python3 -m pip install -r requirements.txt
npm ci
python3 tools/pattern.py
python3 tools/layout.py
python3 tools/elevation.py
python3 tools/print_files.py
python3 tools/verify_pack.py
npm run build
python3 -m http.server 8000 --directory docs
```

Проверка сверяет 20 пар стачных швов по общей пространственной границе, длине и числу стежков, проверяет замкнутость и размеры контуров раскладки, страницы A3 и A4 и физические размеры обоих калибров в готовом PDF.
